# Caption sources

Every claim in a caption that comes from outside the page, with where it comes from. Numbers that
come from the page itself (level length, jump height, screen counts, tallest column, bounces in
the rally) are imported from the world's own code in its `captions.ts`, so they cannot drift and
need no row here.

Rules: examples stay generic (no real game names or characters on the page; "Pong" and years are the
only exceptions). Names appear in this file only to say where a fact comes from. Never invent a
statistic. A claim that could not be confirmed is listed under "Left out" and is not on the page.
When you add a claim to a caption, add a row here in the same change.

Checked on **2026-10-19**. "Sure" is how confident the page's wording is, given what was read:
high = read in the source itself (or two independent sources agree); medium = one source read, or
a search excerpt of an official page that did not load; low = not used.

## Left out (could not be confirmed, or too weak to print)

- How long a decompilation takes in years or months (the three projects above give no dates in their
  READMEs; news pieces disagree: one game is reported done in 2019, another in 2021, 2022 or 2023,
  "nearly two years" appeared in one excerpt whose page returned 403). The page says only that it
  is slow, as the terminal's script already does.
- That most games never get a decompilation (already in the terminal's script, an owner statement; no source found).
- That a decomp-based port can run at any resolution or frame rate. One guide says so
  (https://heldgames.com/guides/retro-decompilation-recompilation-explained) but it is a secondary
  source, and two of the READMEs above state they are "not producing a PC port".
- Numbers from REA's own README page (star counts, "3,205 cases", "63 function bytes"): unverified by
  us, and the star counts looked implausible.
- Fixed-point speeds on the 6502 (a secondary write-up only).
- The mod-framework history of the block game beyond one sentence (MCP, Forge): the sources read
  do not cover it.
- Exact paddle return angles and the 4-hit / 12-hit speed-up thresholds of arcade Pong (sources disagree).
- Mojang's 2025 announcement that it would stop obfuscating the Java Edition: seen only in a secondary
  report (adtmag.com); official page timed out. Not used.
- Whether Ghidra's decompiler output is "C-like": not stated on the pages read, so the page says
  "readable pseudocode".
